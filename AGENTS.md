- **Seed data**: `scripts/seed.ts` defines every row in `data.db`. Read it when you need sample users, courses, or other existing records.
- **Routes** are registered explicitly in `app/routes.ts`; a new route file needs an entry there. Route types (`./+types/<route>`) are generated by `npm run typecheck`.
- **Services** in `app/services/` hold the data access and take positional parameters. Routes call services rather than `db` directly.
- **Tests**: `npx vitest run <path>` runs one file; add `-t "<name>"` for one test. Service tests mock `~/db` with `createTestDb()` from `app/test/setup.ts`, which replays `drizzle/`, so a schema change needs its migration generated before tests see it.
- **Auth** is dev-only: the session holds a `userId`, switched through the DevUI panel. Course permissions live in `app/lib/access.server.ts` (`getAccess`, `requireStaff`, `requireContentAccess`).
- **`app/db/index.ts`** opens the connection lazily so `better-sqlite3` stays out of the client bundle; keep it free of side effects.
